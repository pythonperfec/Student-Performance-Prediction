Working pipeline

  1. Generate a reproducible synthetic cohort (python -m src.generate_dataset).
  2. Preprocess with median imputation + scaling for numbers, mode + one-hot for categories.
  3. Compare Ridge, Random Forest, and HistGradientBoosting with 5-fold CV on 80% of rows.
  4. Persist the winning Pipeline with joblib so inference never re-implements encoding.
  5. Serve HTML via Jinja + HTMX and JSON via POST /api/v1/predict.
